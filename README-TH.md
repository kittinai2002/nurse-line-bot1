# เหมียวเตือนเวร — ใช้งานใน LINE

เวอร์ชัน 2.6.0 รองรับ Vercel + Neon + ตัวเรียกเตือนทุกนาที ใช้ใน LINE อย่างเดียว ไม่มีเว็บหรือ LIFF เพิ่มเติม

**ขึ้น Vercel:** เริ่มที่ `VERCEL-START-HERE-TH.txt` ถ้ามีตารางเดิมอ่าน `VERCEL-MOVE-OLD-DATA-TH.txt` ด้วย โค้ดพร้อมเตรียมติดตั้ง แต่ยังไม่ได้เปิดระบบจริงบนบัญชีผู้ใช้

**ผู้มีบอตเดิม:** อ่าน `UPDATE-LINE-SIMPLE-TH.txt` แล้วอัปเดต `src`, `scripts`, `test` และ `package.json` โดยเก็บ `.env` และ `data` เดิมไว้

## ใช้งาน

ส่ง **เมนู** ในแชต OA จะมีเพียง 3 ปุ่ม:

- **เวรวันนี้** ดูเวลาเวรวันนี้ และกดดูพรุ่งนี้ต่อได้
- **ตารางของฉัน** ดูปฏิทินครบเดือน แตะวันที่ เลือกเวร แล้วกดบันทึก
- **ตั้งค่า** ตั้งเวลาแต่ละเวร ระยะเตือน และเปิด/ปิดแจ้งเตือน

แตะวันที่ในปฏิทินแล้วเวรเดิมถูกเลือกไว้ให้ รองรับหลายเวรในวันเดียวกันและวันหยุด ลบเวรต้องยืนยันอีกครั้ง หากต้องลงหลายวันพร้อมกัน ให้กดปุ่มใต้ปฏิทินแล้วพิมพ์เลขวัน เช่น `1 3 5-7`

ตั้งเวลาเพียงครั้งเดียวก่อนเปิดเตือน ทุกวันที่ลงเวรประเภทเดียวกันใช้เวลานั้น วันที่เวรหมายถึงวันที่เริ่มเวรจริง ใช้เวลาประเทศไทย

## ติดตั้ง Windows

อ่าน `START-HERE-TH.txt` ใช้ Node.js 24 เปิด `01-SETUP.cmd` ครั้งแรก แล้วเปิด `02-START-BOT.cmd` และ `03-START-TUNNEL.cmd` ค้างไว้ ตรวจบอตด้วย `04-CHECK.cmd`

Webhook URL เป็นลิงก์ HTTPS ปัจจุบันของ tunnel เติม `/webhook` การเปลี่ยนหน้าตาไม่แก้ปัญหา tunnel ที่หยุดทำงานหรือ URL เก่า

## การออกแบบ

ใช้แนวทาง component ของ Nucleus UI: การ์ดพื้นขาว ข้อความอ่านง่าย ปุ่มหลักชัด ระยะห่างสม่ำเสมอ สีแยกเช้า/บ่าย/ดึก/หยุด ใช้แมวเป็นเครื่องหมายเล็ก ๆ ข้อความทั่วไปไม่ใส่กรอบตกแต่งซ้อน ปุ่มเลือกเวรจัดเป็นสองคอลัมน์ ไม่ซ้ำกับ Quick Reply

## ข้อมูลและการทดสอบ

แต่ละคนใช้แชตส่วนตัวกับ OA เดียวกัน แยกฐานข้อมูลรายคน บัญชีใหม่ปิดการเตือนไว้ก่อน เก็บฐานเดิมของเจ้าของไว้ที่เดิม ไม่ใช้กับกลุ่ม ไม่มีตารางจริงหรือข้อมูลผู้ป่วยติดมากับไฟล์

ติดตั้งด้วย `npm ci` แล้วทดสอบด้วย `npm test` ผ่าน 42 รายการ (รวมชุด Vercel/การเก็บออนไลน์): ตาราง การข้ามวัน เวรทับซ้อน ยืนยันก่อนบันทึก การแยกคน การรีสตาร์ต การรับ webhook ซ้ำ และเส้นทางใช้งานแบบใหม่ ไม่ได้ส่ง LINE จริงในรอบนี้

สำรองทั้งโฟลเดอร์ `data` หลังหยุดบอต `.env` เก็บความลับ ห้ามแชร์ เก็บคอมที่รันบอตให้เปิดและมีอินเทอร์เน็ตตลอดช่วงเตือน โฮสต์ Docker ใช้ Node.js 24 และ persistent volume `/data`
