เหมียวเตือนเวร 2.5.0 — Windows / LINE
===================================

มีบอตเดิมแล้ว: อ่าน UPDATE-LINE-SIMPLE-TH.txt ก่อน ไม่ต้องติดตั้งบัญชีใหม่
ไม่มีเว็บหรือ LIFF ที่ต้องตั้งค่าเพิ่ม

ติดตั้งครั้งแรก
1. แตก ZIP ออกทั้งหมด แล้วติดตั้ง Node.js 24 LTS:
   https://nodejs.org/en/download
2. เปิด 01-SETUP.cmd กรอก Channel secret, Channel access token และ Your user ID ใน .env
   ใช้จาก Messaging API ของ OA เดียวกัน ห้ามใช้ Channel ID หรือ @LINE ID แทน Your user ID
   เก็บ .env ไว้ในเครื่อง ไม่ส่งในแชต
3. เปิด 02-START-BOT.cmd ค้างไว้ แล้วเปิด 04-CHECK.cmd ให้ขึ้นผ่าน
4. วาง cloudflared.exe ข้างไฟล์ CMD แล้วเปิด 03-START-TUNNEL.cmd
   ดาวน์โหลดจาก https://developers.cloudflare.com/tunnel/downloads/
5. คัดลอกลิงก์ HTTPS จริงที่แสดง เติม /webhook ไปตั้งใน LINE Developers > Messaging API
   กด Update และ Verify ให้ Success แล้วเปิด Use webhook
   ปิดข้อความตอบกลับทั่วไปของ OA ที่ชนกับบอต
6. เพิ่มเพื่อน OA แล้วส่ง เมนู ในแชตส่วนตัว

ใช้งานทุกวัน
• เมนูมี เวรวันนี้ / ตารางของฉัน / ตั้งค่า
• ลงเวร: ตารางของฉัน > แตะวันที่ > เลือกเวร > บันทึก
• ตั้งเวลา: ตั้งค่า > เปลี่ยนเวลาเวร > ใช้เวลาชุดนี้
• เมื่อมีเวรและยืนยันเวลาพร้อมแล้ว เปิดแจ้งเตือนในตั้งค่า
• เวรดึกใช้วันที่เริ่มเวรจริง ไม่ใช่วันที่ออกเวร
• คอมต้องเปิด มีอินเทอร์เน็ต และไม่ Sleep ในช่วงที่ต้องส่งเตือน
• ต้องเปิดบอตและ tunnel ค้างไว้เพื่อรับคำสั่งใน LINE
• เมื่อเปิด tunnel ใหม่ ลิงก์อาจเปลี่ยน ต้องแก้ Webhook URL ให้ตรงกัน
• ถ้าแสดง 530 ตรวจลิงก์ tunnel ล่าสุดและหน้าต่าง tunnel ก่อน
• พอร์ตเริ่มต้น 3000 ถ้าเปลี่ยนให้แก้ PORT ใน .env แล้วเปิดบอตและ tunnel ใหม่
• ตารางอยู่ใน data สำรองหลังหยุดบอต ห้ามลบโฟลเดอร์นี้

ลิงก์ตรวจบอต http://127.0.0.1:3000/healthz
หน้านี้เป็นสถานะเท่านั้น การลงเวรทำในแชต LINE
