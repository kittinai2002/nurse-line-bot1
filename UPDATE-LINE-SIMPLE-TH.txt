รุ่น 2.5.0 — ใช้ใน LINE อย่างเดียว
==================================

เมนูหลักมี 3 ปุ่ม
เวรวันนี้ | ตารางของฉัน | ตั้งค่า

ลงหรือแก้เวร
1. เปิด ตารางของฉัน
2. แตะวันที่ แล้วแตะ เช้า / บ่าย / ดึก / หยุด
3. กด บันทึกเวร

เวรเดิมถูกเลือกไว้ให้ กดเวรที่มีเครื่องหมาย ✓ เพื่อเอาออก
เลือกได้หลายเวรในวันเดียวกัน แต่ระบบจะไม่ให้บันทึกเวลาที่ทับซ้อนกัน
กด ยกเลิก หากยังไม่ต้องการเปลี่ยนข้อมูล
ลบเวร: แตะวันที่ > ลบเวรวันที่เลือก > ยืนยันลบเวร
วันนั้นจะกลับเป็นยังไม่ลงเวร ซึ่งต่างจากวันหยุด

ตั้งเวลาครั้งแรก
เมนู > ตั้งค่า > เปลี่ยนเวลาเวร
• เวลาตรงกับที่ทำงานแล้ว กด ใช้เวลาชุดนี้ ได้เลย
• เวลายังไม่ตรง กดแก้เวรเช้า/บ่าย/ดึก เลือกเวลาเริ่มและเวลาเลิก
• เมื่อครบ กด ใช้เวลาชุดนี้ แล้วกลับตั้งค่าเพื่อเปิดแจ้งเตือน
• เตือนก่อนขึ้นเวร เลือกจำนวนนาทีได้จากปุ่ม

อัปเดตจากบอตเดิม (ใช้ข้อมูลเดิม)
1. ที่หน้าต่างบอต กด Ctrl+C แล้วสำรองโฟลเดอร์บอตเดิมไว้
2. แตก ZIP ใหม่ แล้วคัดลอก src, scripts, test และ package.json ไปทับของเดิม
3. เก็บ .env และโฟลเดอร์ data ของเดิมไว้ ห้ามลบหรือแทนที่
4. เปิด 02-START-BOT.cmd แล้วส่งคำว่า เมนู ใน LINE

ไม่ต้องสร้าง LINE Login ไม่ต้องตั้ง LIFF ไม่ต้องเปิดเว็บ
ไม่ต้องเปลี่ยน Webhook หาก tunnel เดิมยังเปิดและใช้ลิงก์เดิมอยู่
หากเปิด tunnel ใหม่จนลิงก์เปลี่ยน ต้องอัปเดต Webhook URL ตามเดิม
รุ่นนี้ไม่ได้เปลี่ยนการเชื่อม tunnel ปัญหา 530 ต้องแก้ลิงก์/การเชื่อมต่อให้ผ่านก่อน

หน้าตา
การ์ดพื้นขาว ตัวอักษรเข้ม ปุ่มหลักเด่น ระยะห่างสม่ำเสมอ
อิงแนวทาง component ของ Nucleus UI พร้อมสีแยกประเภทเวร
เป็น Flex Message ภายใน LINE ไม่ใช่นำหน้าจอ Figma หรือเว็บมาใส่โดยตรง
สี/อีโมจิและการจัดวางจริงอาจต่างกันตามมือถือ

ทดสอบอัตโนมัติ 32 รายการผ่านด้วย API จำลอง ยังไม่ได้ส่ง LINE จริงในรอบนี้
ตาราง/เวลาเดิมและการแยกบัญชีรายคนยังคงอยู่ ไม่เปิดแจ้งเตือนให้เอง
