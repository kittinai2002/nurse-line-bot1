ย้ายตารางเดิมจาก Windows ไป Vercel
===================================

ทำหลังสร้าง Neon และ Run schema/vercel.sql แล้ว
ทำก่อนเปลี่ยน Webhook ไป Vercel และก่อนให้คนเริ่มลงข้อมูลบนระบบใหม่

1. ที่หน้าต่างบอต Windows กด Ctrl+C เพื่อหยุดการส่งเตือนตัวเก่า
2. สำรองโฟลเดอร์บอตทั้งโฟลเดอร์ โดยเฉพาะ .env และ data
3. วางโค้ดชุดใหม่ในโฟลเดอร์บอตเดิม เก็บ .env และ data เดิมไว้
4. เปิด 07-SETUP-VERCEL.cmd ใส่ DATABASE_URL จาก Neon แล้ว Save
   LINE_OWNER_USER_ID ต้องยังเป็นเจ้าของเดิม
5. ในโฟลเดอร์นี้ คลิกช่องที่อยู่ของ File Explorer พิมพ์ cmd แล้ว Enter
   พิมพ์ npm ci แล้วรอจนติดตั้งเสร็จ
6. ตรวจแบบไม่เขียนออนไลน์ก่อนด้วยคำสั่ง:
   npm run cloud:import
   จะบอกจำนวนบัญชีที่พบ แต่ยังไม่เขียนฐานออนไลน์
7. เมื่อตรวจพร้อม เปิด 08-IMPORT-TO-VERCEL.cmd
   โปรแกรมอ่าน data เดิมและบันทึกไป Neon โดยไม่แก้หรือลบไฟล์เดิม
8. หลังย้าย: ไปเปลี่ยน Webhook ไปที่ Vercel ตามคู่มือติดตั้ง
9. ส่ง เมนู ใน OA ตรวจตาราง/เวลา แล้วเปิดแจ้งเตือนใหม่ของแต่ละคน

สิ่งที่ย้าย
• ตารางเวรและเวลาเดิมของแต่ละคน
• ระยะเตือนและการยืนยันเวลาเดิม
• ประวัติการส่งและ retry key เพื่อช่วยกันส่งซ้ำ

สิ่งที่ตั้งใจเปลี่ยน
• พักแจ้งเตือนทุกบัญชีหลังย้าย รอแต่ละคนตรวจและเปิดอีกครั้ง
• ไม่ย้ายร่างที่ยังไม่บันทึกหรือปุ่มยืนยันค้างในแชต

ป้องกันข้อมูลหาย
• บัญชีที่มีข้อมูลออนไลน์อยู่แล้วจะถูกข้าม ไม่เขียนทับ
• ถ้าย้ายไปแล้วบางบัญชี สามารถรันซ้ำเพื่อย้ายเฉพาะบัญชีที่ยังไม่มีได้
• ถ้ามีตารางใหม่บน Vercel แล้ว อย่าลบฐานออนไลน์เพื่อเริ่มนำเข้าใหม่
• ห้ามเปิดบอต Windows ตัวเก่าพร้อมระบบ Vercel หลังเริ่มใช้งานจริง อาจได้รับเตือนจากทั้งสองฝั่ง
• เก็บไฟล์สำรองเดิมไว้ หากย้อนกลับไป Windows ตารางที่แก้บนออนไลน์จะไม่ย้อนกลับมาด้วยอัตโนมัติ

อย่าส่ง .env.vercel หรือ Connection string ในภาพ/แชต
